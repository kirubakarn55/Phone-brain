# Phone Brain

Phone Brain is a futuristic AI-inspired phone dashboard built using HTML, CSS, and JavaScript.

## Features
- Digital Cyberpunk Clock
- Battery, CPU & RAM Dashboard
- Voice Commands
- Gaming Mode
- Study Mode
- AI Orb Interface
- Progressive Web App (PWA)
- Responsive Mobile Design

## Technologies
- HTML5
- CSS3
- JavaScript
- Service Workers
- Web Speech API
